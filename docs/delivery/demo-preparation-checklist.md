# 演示准备清单

**规格**: Spec 16 · Ticket #118  
**更新日期**: 2026-10-20

## 目的

本清单为演示者提供可执行的准备步骤，确保演示环境就绪且数据可复现。

## 环境准备

### 1. 运行时环境

- [ ] Node.js 24.15.0 或更高（验证：`node --version`）
- [ ] Bun 1.4.3（验证：`bun --version`）
- [ ] Chromium 已安装（验证：`bun run agent:doctor`）

### 2. 项目依赖

```bash
# 从项目根目录执行
bun install --frozen-lockfile
```

### 3. 环境变量（可选）

创建 `.env.local` 文件（如需地图功能）：

```
VITE_MAPBOX_ACCESS_TOKEN=你的_mapbox_token
```

**重要**：

- 演示可在无 Mapbox token 时运行，地图功能会显示配置指引
- 不要在录制中暴露真实 token
- 不要提交 `.env.local` 到版本控制

### 4. 开发服务器

```bash
# 启动开发服务器（用于演示准备和测试）
bun run dev

# 访问 http://127.0.0.1:3000
```

或生产构建：

```bash
bun run build
bun run start

# 访问 http://127.0.0.1:3000
```

## 账号与数据准备

### 固定演示账号

MeteoWeave 使用三个公开固定演示账号：

| 账号标识      | 角色     | 密码         | 能力                               |
| ------------- | -------- | ------------ | ---------------------------------- |
| `researcher`  | 研究人员 | `meteo-demo` | 完整配置：确定性、概率式、高级选项 |
| `policy`      | 决策者   | `meteo-demo` | 仅推荐方法                         |
| `agriculture` | 农业用户 | `meteo-demo` | 仅推荐方法                         |

**重要**：

- 这是公开演示密码，不是生产凭证
- 所有账号共享相同密码 `meteo-demo`
- 数据按账号隔离，不同账号看不到彼此的任务

### 初始数据恢复

**首次使用会自动初始化**：

1. 访问 `/login`
2. 选择任一账号登录
3. 进入工作区（如 `/tasks`）
4. 系统自动保存四个内置案例到当前账号

**内置案例**：

- 山地气温（确定性方法）
- 沿海平原风（确定性方法）
- 高原海平面气压（概率式方法）
- 低地平原降水（概率式方法）

**数据特性**：

- 使用 Synthetic Demo 数据，不是真实天气资料
- 结果可复现，seed 固定
- 删除案例后不会自动恢复（需重新初始化账号或恢复操作）

## 时区与时间

### 系统时钟

- 演示使用系统当前时间
- 预测任务窗口：当前 UTC 小时起 7 天内
- 历史任务窗口：2020-2024 年

### 推荐设置

```bash
# 检查系统时区
date

# 演示建议使用当前真实时间，无需调整
```

**注意**：

- 任务提交时间验证在服务器端进行
- 避免在录制中显示过期的预测窗口
- 历史任务示例使用 2023 年数据

## 浏览器准备

### Chromium/Chrome（推荐）

- 最新稳定版
- 启用开发者工具（可选，用于调试）
- 清除缓存和 Cookie（可选，确保干净演示）

### 窗口大小建议

- **桌面录制**：1440px 宽度（标准桌面布局）
- **平板录制**：768px 宽度（展示响应式布局）
- **手机录制**：390px 宽度（最小支持宽度）

### 键盘可访问性演示

- 准备键盘导航演示（Tab、Enter、Escape）
- 准备屏幕阅读器（可选，如需演示辅助功能）

## 网络与资源

### 本地模式

- 所有数据在浏览器 IndexedDB 中
- 无需外部 API 或数据库连接
- 合成结果本地生成，无远程模型调用

### Mapbox 地图（可选）

- **有 token**：显示完整地图交互
- **无 token**：显示配置指引，不阻塞其他功能
- 建议：录制前决定是否展示地图功能

### 加载失败恢复

演示时可能遇到的场景：

- 模块加载失败：显示重新加载选项
- 地图 token 缺失：显示配置指引
- 网络中断：显示错误恢复界面

**准备**：熟悉这些恢复路径，作为健壮性演示点

## 演示前检查

### 快速验证

```bash
# 运行快速检查
bun run agent:doctor

# 验证应用启动
bun run dev
```

访问关键路径：

- [ ] `/` - 入口页正常显示
- [ ] `/login` - 登录表单可用
- [ ] `/dashboard` - 需登录后访问
- [ ] `/tasks` - 任务列表显示内置案例
- [ ] `/tasks/<id>` - 结果分析页面正常

### 数据准备验证

以 `researcher` 账号登录：

- [ ] 任务列表显示 4 个内置案例
- [ ] 点击案例可进入结果分析
- [ ] 五个分析标签页均可访问
- [ ] 下载功能可用（CSV/JSON/NetCDF）

### 常见问题排查

**Q: 登录后显示空任务列表**
A: 首次登录需要几秒初始化。刷新页面或等待初始化完成。

**Q: 地图显示配置提示**
A: 正常现象，无 Mapbox token 时的预期行为。继续演示其他功能。

**Q: 任务结果加载慢**
A: 首次查询会计算合成数据。后续访问使用缓存会更快。

## 录制技术准备

### 屏幕录制工具

推荐设置：

- 分辨率：1920x1080 或 2560x1440
- 帧率：30fps 或 60fps
- 音频：根据是否需要旁白决定

### 演示流程

1. **开场**：显示入口页，说明平台定位
2. **登录**：展示三种账号选择
3. **角色旅程**：按录制脚本执行
4. **收尾**：展示退出或角色切换

### 后期剪辑考虑

- 添加字幕说明（可选）

## 安全注意事项

### 不要录制

- ❌ 真实环境变量文件（.env）
- ❌ 浏览器开发者工具中的敏感信息
- ❌ 系统路径或个人信息
- ❌ 实际生产凭证

### 可以展示

- ✅ 公开演示密码（meteo-demo）
- ✅ 固定账号标识（researcher/policy/agriculture）
- ✅ Synthetic Demo 数据和结果
- ✅ 配置指引和错误恢复

## 备选方案

### 场景 A：完整地图演示

需要有效 Mapbox token，展示地图交互、网络控制、空间分析

### 场景 B：无地图演示

聚焦于任务管理、角色能力、数据分析、文件下载

### 场景 C：恢复路径演示

展示错误恢复、模块失败处理、安全返回

**建议**：准备场景 A 或 B，将场景 C 作为备用健壮性演示点
