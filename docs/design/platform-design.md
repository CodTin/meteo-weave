# 气象降尺度Demo平台 - 完整设计方案

## 1. 平台定位与目标

**平台性质**：功能完善的MVP产品，用于录制演示视频
**核心价值**：展示降尺度技术的完整功能流程和应用价值
**设计原则**：
- 功能完善但不考虑edge case
- 重点在功能展示而非实际高强度使用
- 使用Mock数据和预计算结果，模拟真实体验

---

## 2. 用户角色与权限

### 2.1 支持的角色
- **研究人员**：关注技术指标和模型细节
- **决策者**：关注应用场景和决策支持
- **农业用户**：关注农业相关气象指标

### 2.2 角色差异化

#### 任务配置参数差异
- **研究人员**：完整参数控制
  - 数据源选择（ECMWF、GFS、融合）
  - 时间空间范围
  - 变量选择
  - 降尺度方法（确定性、概率式、推荐）
  - 目标分辨率（1km/3km/5km）
  - 高级参数（模型集成、不确定性量化）

- **决策者和农业用户**：中等参数权限
  - 数据源选择
  - 时间空间范围
  - 变量选择
  - 目标分辨率
  - 方法使用推荐默认值

#### 结果展示差异
- **研究人员**：侧重技术指标（RMSE、MAE、相关系数、空间谱分析）
- **决策者**：侧重应用信息（极端事件预警、影响评估、置信区间）
- **农业用户**：侧重农业指标（生长度日、降水概率、霜冻预警）

### 2.3 角色切换
- 在用户设置页面切换角色
- 预设不同身份角色账号
- 切换角色需要重新登录

### 3.1 Dashboard（登录后首页）

```
┌─────────────────────────────────────────────────────┐
│ 顶部：个人信息（角色、用户名） + 快速操作按钮          │
```

### 3.2 数据查询与任务配置

#### 3.2.1 界面布局：左右分栏

```
┌──────────────────┬────────────────────────┐
│                  │                        │
│  左侧：参数表单   │  右侧：实时预览         │
│                  │                        │
│  ▼ 数据配置      │  ┌──────────────────┐ │
│  ▼ 时空范围      │  │   地图显示选中    │ │
│  ▼ 降尺度配置    │  │   区域            │ │
│                  │  └──────────────────┘ │
│                  │  参数摘要卡片          │
│                  │  预估计算时间          │
│  [提交任务]      │                        │
└──────────────────┴────────────────────────┘
```

#### 3.2.2 参数配置详情

**数据配置**
- 数据源选择
  - ECMWF（欧洲中期，精度高）
  - GFS（美国全球，更新快）
  - 融合（推荐，综合优势）
- 变量选择（合并U10/V10为风速风向）
  - 气温（T2M）
  - 风速风向（U10/V10）
  - 海平面气压（MSL）
  - 总降水（TP）

**时空范围配置**
- 时间模式切换：历史分析 / 预测模式
  - **历史模式**：按日选择，支持2020-2024年
  - **预测模式**：按小时选择，支持未来7天
- 空间范围选择
  - 地图交互：在地形底图上框选矩形区域
  - 表单输入：输入经纬度范围（南北纬度、东西经度）
  - 地图和表单联动更新
  - 支持任意范围选择（数据为Mock）
  - 提供地点搜索功能

**降尺度配置**
- 方法选择
  - **确定性方法**（EDSR超分）：速度快，结果稳定，适合快速预览
  - **概率式方法**（扩散模型）：细节丰富，表达不确定性，适合研究分析
  - **推荐方法**（默认）：智能选择最优方法
- 目标分辨率
  - 标准模式：3km
  - 高精度模式：1km
  - 快速模式：5km

#### 3.2.3 地图设计
- 底图：地形底图为主（突出地形对气象的影响）
- 交互：缩放、平移、地点搜索
- 实时显示选中区域的边界框

### 3.3 任务提交与处理

#### 提交流程
1. 用户点击"提交任务"
2. 显示加载动画（2-3秒模拟处理）
3. 进度提示文字：
   - "正在加载数据..."
   - "执行降尺度..."
   - "生成结果..."
4. 自动跳转到结果页面

#### 技术实现
- 使用预计算的结果
- 模拟快速响应（秒级）
- 数据可以是Mock的

### 3.4 结果展示（5个Tab）

#### 3.4.1 Tab 1: 地图对比

**布局模式**
- 默认：2×2网格布局
  ```
  ┌──────────┬──────────┐
  │ 原始数据  │ 降尺度    │
  ├──────────┼──────────┤
  │ 观测数据  │ 差异图    │
  └──────────┴──────────┘
  ```
- 可切换：1×4横排、单图大图模式

**交互功能**
- **联动操作**：4张地图同步缩放、平移
- **悬停提示**：显示该点的四种数值（原始、降尺度、观测、差异）
- **点击详情**：弹出卡片显示精确数值和改进百分比

**配色方案**
- 默认使用行业标准配色
  - 气温：蓝-红渐变
  - 降水：白-蓝-深蓝渐变
  - 气压：紫-白-橙渐变
  - 风速：绿-黄-红渐变
- 提供色阶调整功能（自动/手动范围）
- 提供自定义配色入口

**观测数据展示**
- 双视图支持：
  - 点位视图：显示原始台站数据和数值
  - 插值视图：插值成栅格便于对比
- 视图切换开关

---

#### 3.4.2 Tab 2: 精度评估

**分组卡片布局**

1. **整体精度卡片**
   - 指标：RMSE、MAE、R²
   - 可视化：散点图（观测 vs 预测）

2. **分布特征卡片**
   - 指标：偏差、标准差、分位数对比
   - 可视化：箱线图对比

3. **空间结构卡片**
   - 指标：空间相关性
   - 可视化：功率谱图

4. **极端事件卡片**
   - 指标：极值捕捉率、极端事件预警准确率
   - 可视化：极值对比柱状图

**角色差异化展示**
- 研究人员：展示所有技术指标
- 决策者：突出极端事件和置信区间
- 农业用户：突出与农业相关的阈值指标

#### 3.4.4 Tab 4: 空间分析

## 4. 技术特性

- 配色方案：气象行业标准配色 + 自定义选项

### 4.3 用户体验
- 实时预览：参数配置时即时显示效果

- 进度反馈：任务提交时的模拟进度

## 5. 完整用户流程

### 5.1 首次使用流程

1. **登录/注册**
   - 选择角色（研究人员/决策者/农业用户）
   - 输入账号信息

2. **进入Dashboard**
   - 查看个人信息和任务统计
   - 点击"创建新任务"

3. **配置任务**
   - 选择数据源和变量
   - 在地图上框选区域（或输入经纬度）
   - 选择时间模式和时间范围
   - 选择降尺度方法和分辨率
   - 右侧实时预览选中区域
   - 提交任务

4. **查看结果**
   - 等待2-3秒加载
   - 进入结果页面，默认显示"地图对比"Tab
   - 依次浏览各个Tab
   - 在"数据导出"Tab下载数据

5. **任务管理**
   - 返回Dashboard查看任务列表
   - 选择历史任务重新查看
   - 对比不同参数的任务结果

### 5.2 角色切换流程

1. 点击右上角用户头像
2. 选择"设置"
3. 在"账号设置"中选择"切换角色"
4. 选择新角色
5. 重新登录（使用预设的对应角色账号）
6. 进入Dashboard，界面和参数权限已切换

## 6. 设计亮点总结

### 6.1 功能完善性
- **5个完整的结果分析Tab**：从地图对比到空间分析，覆盖多维度评估
- **完整的任务管理**：列表、筛选、排序、对比功能齐全
- **灵活的参数配置**：支持完整的降尺度参数自定义

### 6.2 用户体验
- **实时预览和反馈**：配置时即时显示效果，下载前预估数据量
- **联动交互**：多图同步操作，提升对比效率
- **多种选择方式**：地图点击、表单输入、快捷选择并存

### 6.3 角色差异化
- **参数权限分级**：研究人员完整控制，决策者简化操作
- **结果展示差异**：针对不同角色突出不同指标
- **灵活的角色切换**：便于演示不同用户视角

### 6.4 专业性
- **气象行业标准**：配色、指标、术语符合行业规范
- **三方对比可视化**：原始-降尺度-观测全面对比
- **多种数据格式**：CSV、GeoJSON、NetCDF满足不同需求

### 6.5 Demo适配性
- **快速响应**：预计算结果，无需等待
- **Mock数据**：不受真实数据限制
- **完整功能流程**：从配置到结果到下载的闭环
